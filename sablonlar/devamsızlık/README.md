# Devamsizlik sablonlari

Bu klasore ogrenci ve devamsizlik belgelerinin sabit PDF sablonlari konur.

Beklenen sablonlar:

- veli_devamsizlik_izin_dilekcesi.pdf
- genel_devamsizlik_raporu.pdf
- esik_raporu.pdf
- gec_kalanlar.pdf

`veli_devamsızlık_izin_dilekçesi.pdf`, programdaki mevcut veli izin formunun
sayfa ölçüsü, çerçevesi, tablo çizgileri ve imza alanları korunarak kullanılacak
referans şablondur.

Şablon dosyası henüz eklenmediyse program mevcut çizim koduyla çalışmaya devam eder.
