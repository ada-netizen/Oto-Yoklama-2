# Ihale sablonlari

Bu klasore ihale belgelerinin sabit PDF veya Excel sablonlari konur.

Beklenen sablonlar:

- fiyat_isteme.pdf
- ozel_fiyat_isteme.pdf
- yaklasik_maliyet.xlsx veya yaklasik_maliyet.pdf
- piyasa_fiyat_arastirmasi.pdf
- muayene_kabul.pdf

Excel sablonlari, PDF sablonlarindan farkli olarak hesap ve tablo yapisini korumak icin kullanilabilir.
