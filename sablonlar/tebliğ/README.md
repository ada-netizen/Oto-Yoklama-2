# Teblig sablonlari

Bu klasore teblig ve personel belgelerinin sabit PDF sablonlari konur.

Beklenen sablonlar:

- bireysel_teblig.pdf
- toplu_imza_sirkusu.pdf
- personel_listesi.pdf

Bireysel teblig icin once bireysel_teblig.pdf eklenecek. Program bu PDF'yi arka plan olarak kullanip degisken bilgileri uzerine yazacak.
